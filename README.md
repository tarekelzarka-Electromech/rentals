# Rentals

Short-stay rental investment planner and tracker for iPhone (web app).

- Plan tenders: investment items (EGP/USD), funding by owner / operator / investors, seasons, operator fee, capital return with interest.
- Run projects: record bookings, expenses, payouts and actual investment; compare actual vs budget.
- Reports and PDF per project, plus a portfolio dashboard.

All data is stored **on the device only** (browser storage). Nothing is sent to any server.
Use **Settings › Back up all data** regularly and keep the backup file in Files / iCloud.

Open on iPhone in Safari → Share → **Add to Home Screen**.
